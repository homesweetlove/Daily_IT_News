[회사 발표](https://investor.workday.com/news-and-events/press-releases/news-details/2026/Workdays-Trusted-Agent-Platform-Now-Delivers-Headless-Access-to-HR-and-Finance-Letting-Customers-Build-and-Run-Lawful-AI-Agents/default.aspx) · [배포 시각 확인](https://www.prnewswire.com/news-releases/workdays-trusted-agent-platform-now-delivers-headless-access-to-hr-and-finance-letting-customers-build-and-run-lawful-ai-agents-302906696.html)
- **핵심 요약:** Workday는 Agent Harness, Agent-Ready Tools, Developer Agent, Custom Agents, Workday Data Cloud의 일반 제공을 발표했다. MCP를 지원하는 에이전트가 인사·재무 데이터와 작업에 접근할 수 있도록 하되 기존 권한·승인·감사 기록을 적용한다는 설명이다. [기능·제공 범위](https://investor.workday.com/news-and-events/press-releases/news-details/2026/Workdays-Trusted-Agent-Platform-Now-Delivers-Headless-Access-to-HR-and-Finance-Letting-Customers-Build-and-Run-Lawful-AI-Agents/default.aspx)

[공식 Availability·예정 기능](https://investor.workday.com/news-and-events/press-releases/news-details/2026/Workdays-Trusted-Agent-Platform-Now-Delivers-Headless-Access-to-HR-and-Finance-Letting-Customers-Build-and-Run-Lawful-AI-Agents/default.aspx)

- **새 보도 시각:** The Next Web 10월 13일 10:21 UTC(한국시간 19:21). Mozilla 원 발표는 10월 12일자이므로 오늘 최초 발표로 표현하지 않는다. [새 보도](https://thenextweb.com/news/mozilla-launches-firefox-enterprise-for-companies-in-europ) · [Mozilla 원문](https://blog.mozilla.org/en/firefox/introducing-firefox-enterprise/)
- **핵심 요약:** Mozilla는 Gecko 기반 Firefox와 조직 자체 인프라에서 운영할 수 있는 관리 콘솔을 결합했다. 브라우저 정책·접근·데이터 이동·AI 사용을 중앙에서 관리하고, 기존 신원 제공자·SIEM·MDM과 함께 사용하도록 설계했다. [공식 기능 설명](https://blog.mozilla.org/en/firefox/introducing-firefox-enterprise/)

- **관찰 포인트:** 초기 판매 초점은 프랑스·독일·오스트리아·스위스다. 한국 등 다른 지역의 제공 여부를 이 발표만으로 단정하지 말자. Thunderbird Enterprise는 개발 중이며 현재 제공되는 제품과 구분해야 한다. [지역·향후 계획](https://blog.mozilla.org/en/firefox/introducing-firefox-enterprise/)

### 1. Microsoft 10월 업데이트, 실제 악용된 Windows Shell 보호 우회 취약점 수정

- **발표·보도일:** 패치 공개는 10월 13일. BleepingComputer의 새 보도는 19:56 UTC(한국시간 10월 14일 04:56)에 게시됐다. [공식 공지](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-96951) · [새 보도](https://www.bleepingcomputer.com/news/microsoft/microsoft-october-2026-patch-tuesday-fixes-1-411-flaws-3-zero-days/)
- **핵심 요약:** `CVE-2026-96951`은 Windows Shell에서 인터넷에서 받은 파일의 Mark of the Web 보호를 우회할 수 있는 결함이다. 조작 파일을 사용자가 열도록 유도하는 동작이 필요하며, 공식 악용 상태는 `Exploited:Yes`다. [Microsoft 공지](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-96951) · [공식 악용 상태·수정 데이터](https://api.msrc.microsoft.com/cvrf/v3.0/cvrf/2026-Oct)
- **왜 중요한가 — 편집부 해석:** 이미 공격에 쓰인 보호 우회이므로, 일반적인 기능 업데이트와 달리 우선 배포할 보안 항목이다.
- **영향·대응:** Windows 10·11과 여러 Windows Server 버전이 대상이다. 아래는 Windows 11의 대표 수정 빌드이며, 전체 제품·에디션·아키텍처별 적용 여부는 공식 공지에서 확인해야 한다.

[Microsoft 공식 수정 빌드 원장](https://api.msrc.microsoft.com/cvrf/v3.0/cvrf/2026-Oct)

- **관찰 포인트 — 편집부 권고:** 해당 OS의 보안 업데이트를 적용하고 재부팅·설치 빌드를 확인하자. 의심스러운 첨부파일 실행 이력도 점검해야 한다.
- **신뢰도: 높음.** 악용 상태와 위 수정 빌드는 공식 데이터로 확인했다. 공격자·피해 규모·악용 시작일은 공개 자료에서 확인되지 않았다. [공식 공지](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-96951) · [보도](https://www.bleepingcomputer.com/news/microsoft/microsoft-october-2026-patch-tuesday-fixes-1-411-flaws-3-zero-days/)

### 2. SAP Cloud SDK for Python, OAuth2 자격증명 유출 결함 공개…0.45.2로 수정

- **공개·보도 시각:** 공식 권고는 10월 13일 07:33 UTC(한국시간 16:33)에 공개됐으며, 새 보도는 13:51 UTC(한국시간 22:51)에 게시됐다. [SAP 공식 권고](https://github.com/SAP/cloud-sdk-python/security/advisories/GHSA-4mv3-jxxm-9cx2) · [새 보도](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-oauth2-ssrf-security-flaw/)
- **핵심 요약:** `CVE-2026-89111`은 멀티테넌트 BTP 앱의 OAuth2 SSRF 결함이다. 공격자가 `tenant_subdomain` 값을 통제하면 토큰 요청이 공격자 서버로 향해 클라이언트 자격증명이 유출될 수 있다. 공식 공지의 심각도 점수 표기는 10.0이다. [공식 기술 설명](https://github.com/SAP/cloud-sdk-python/security/advisories/GHSA-4mv3-jxxm-9cx2)
- **영향·대응:** Python 패키지 `sap-cloud-sdk <0.45.2`가 대상이고 `0.45.2`에서 수정됐다. 해당 SDK를 사용하는 앱을 확인해 업데이트하자. 즉시 적용이 어렵다면 등록된 테넌트 하위 도메인의 허용 목록으로 입력을 검증하는 공식 우회 조치를 적용한다. [수정 버전·우회 조치](https://github.com/SAP/cloud-sdk-python/security/advisories/GHSA-4mv3-jxxm-9cx2)
- **왜 중요한가 — 편집부 해석:** SDK의 테넌트 입력 처리 문제도 애플리케이션 인증정보 노출로 이어질 수 있다. 패키지 업데이트와 입력 경계 검증을 함께 점검해야 한다.
- **신뢰도: 높음.** 결함과 버전 범위는 공식 권고로 확인했다. 검토한 자료에서 실제 악용은 확인되지 않았다. 자격증명 노출 정황이 있다면 교체와 접근 이력 조사를 병행하자(편집부 권고). [공식 권고](https://github.com/SAP/cloud-sdk-python/security/advisories/GHSA-4mv3-jxxm-9cx2) · [보도](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-oauth2-ssrf-security-flaw/)
