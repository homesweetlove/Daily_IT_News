## IT 이슈

### 1. GitHub Copilot Fusion 정식 제공…로컬 모델 자동 선택은 실험 프리뷰

**핵심 요약:** GitHub는 10월 28일 작업별 모델 선택과 여러 모델의 협업을 맡기는 Copilot Fusion을 정식 제공한다고 발표했습니다. VS Code, Copilot 앱·CLI, JetBrains에서 사용할 수 있으며, 사용자가 Standard·High·Max 노력 수준을 고르면 단일 모델 실행이나 단계적 검토·재작성 등의 방식을 선택합니다. [정식 제공 공지](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/)

**왜 중요한가 — 편집부 분석:** 개발자가 매번 모델을 고르는 대신 작업의 품질·지연·비용을 묶어 관리하는 방향입니다. 다만 모든 업무에서 비용이 절감되거나 코드 품질이 보장된다는 뜻은 아닙니다.

**도입 시 확인할 점:** 조직·기업이 허용한 모델 정책이 적용되며, 요금은 실제 사용한 각 모델의 표준 요율을 기준으로 부과됩니다. 별도로 발표한 로컬·클라우드 모델 자동 선택은 **참여형 실험 프리뷰**입니다. 로컬 추론을 사용해도 라우팅 판단은 클라우드에서 이뤄지므로 완전한 오프라인 세션으로 볼 수 없습니다. [정책·과금](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/) · [로컬 모델 프리뷰와 한계](https://github.blog/changelog/2026-10-28-github-copilot-fusion-now-supports-selection-of-local-models/)

### 2. Microsoft, 분기 매출 923억 달러…Azure 매출 전년 대비 48% 증가

**핵심 요약:** Microsoft는 10월 28일 2027회계연도 1분기(2026년 9월 30일 종료) 실적을 공개했습니다. 매출은 약 **923억 달러**, 전년 동기 대비 19% 증가했습니다. Azure 매출은 약 **332억 달러**로 48% 늘었고, 더 넓은 Microsoft Cloud 지표는 **639억 달러**로 30% 증가했습니다. Azure와 Microsoft Cloud는 같은 지표가 아닙니다. [공식 실적·제품별 매출표](https://www.microsoft.com/en-us/Investor/earnings/FY-2027-Q1/press-release-webcast)

**왜 중요한가 — 편집부 분석:** 대형 클라우드 사업자의 수요 흐름을 보여주는 자료입니다. 다만 Azure 전체 성장률을 AI만의 성장률이나 고객 전체의 투자 수익으로 해석해서는 안 됩니다.

**관찰 포인트:** 보고서는 회계연도 구분과 부문 재편에 따른 과거 수치 재분류를 명시합니다. 전년 비교에는 같은 기준을 사용하고, 공시된 실적과 향후 전망을 구분해야 합니다. 이 항목은 산업 동향 보도이며 투자 권유가 아닙니다. [비교 기준·재분류 안내](https://www.microsoft.com/en-us/Investor/earnings/FY-2027-Q1/press-release-webcast)

## 보안 이슈

### 1. Tailscale 1.104.4 정식 배포…SSH·Serve 수정판 적용 확인 필요

**새로 확인된 내용:** Tailscale **1.104.4**가 10월 28일 01:05:26 UTC(한국 시간 10:05:26)에 정식 릴리스됐습니다. 공개 API에서도 초안·사전 공개판이 아닌 것으로 확인했습니다. 전날 다룬 ‘코드 병합’과 달리, 실제 설치할 수정 버전이 나온 후속 조치입니다. [공식 릴리스](https://github.com/tailscale/tailscale/releases/tag/v1.104.4) · [배포 메타데이터](https://api.github.com/repos/tailscale/tailscale/releases/tags/v1.104.4)

**핵심 요약:** 공급사 권고 TS-2026-014~017은 SSH의 Unix 소켓 포워딩 권한 경계·세션 메모리 문제와 일부 Serve 결함의 수정 버전을 **1.104.4 이상**으로 명시합니다. SSH 악용에는 접속 권한과 기능·정책 조건이 필요하므로, 인터넷의 아무나 임의 서버에 접속할 수 있다는 뜻은 아닙니다. [문제별 조건·수정 버전](https://tailscale.com/security-bulletins#ts-2026-014)

**왜 중요한가 — 편집부 분석:** 수정 코드가 저장소에 있다는 확인만으로 운영 장비가 보호되지는 않습니다. 이제는 배포 여부가 아니라 각 장비에 실제 설치된 버전을 대조해야 합니다.

**대응:** 해당 SSH·Serve 기능을 쓰는 장비를 공식 절차에 따라 1.104.4 이상으로 갱신하고 SSH 접근 정책을 최소화하세요. 즉시 갱신하지 못하고 포워딩도 필요 없다면 `tailscaled` 서비스 환경의 `TS_SSH_DISABLE_FORWARDING=1` 설정과 서비스 재시작 완화책을 검토할 수 있습니다. 이 설정이 모든 Serve 문제까지 해결하는 것은 아닙니다. [공식 업데이트·완화 지침](https://tailscale.com/security-bulletins#ts-2026-014)

**확인 수준:** 정식 배포와 수정 범위는 공식 확인이며, 연구진도 개별 수정 상태를 확인했습니다. 이번 조사에서 실제 악용은 확인하지 못했습니다. 모든 Tailworm·headscale 지적 사항이 해결됐다고 확대하지 않습니다. [공식 설명](https://tailscale.com/blog/tailscale-ssh-findings-fixes) · [연구진 확인](https://tailworm.com/)
