## 보안 이슈

### 1. ConnectWise Cloud Backup, 침해 인정 후 공유 자격증명 무효화

- 새 공지: 2026-10-17 14:01 KST에 침해·접근 중단을 발표하고 18일 02:00 KST에 자격증명 무효화 등을 안내했다. 최초 관련 공지는 16일 17:47 UTC로 조사 구간 밖이며, 이번 선정은 후속 조치 기준이다. [공식 공지](https://www.connectwise.com/company/trust/advisories).
- 핵심 요약: ConnectWise는 Cloud Backup(구 SkyKick)의 애플리케이션 신원에 무단 접근이 발생했다고 밝혔다. Huntress는 관련 자격증명으로 고객 Microsoft 365 테넌트에 실제 무단 인증한 사실을 확인했다. [ConnectWise](https://www.connectwise.com/company/trust/advisories), [Huntress의 직접 조사](https://www.huntress.com/blog/vendor-credential-enables-unauthorized-access).
- 대응: 관련 Cloud Backup·Cloud Management Teams 앱은 삭제하지 말고 비활성화하고, Entra 서비스 주체 로그인·신규 비밀키·권한 변경을 점검한다. 공급업체의 자격증명 폐기와 고객 테넌트에 추가된 비밀키의 조사는 별개다. [조사·대응 지침](https://www.huntress.com/blog/vendor-credential-enables-unauthorized-access).
- 왜 중요한가 — 편집부 해석: 백업 공급업체의 권한이 여러 고객 환경으로 연결되는 공급망 위험이다. 로그와 변경 내역을 보존하면서 고객별 침해 범위를 확인해야 한다.
- 확인 수준: 침해와 무단 인증은 공급사 발표 및 직접 조사로 확인됐다. 전체 피해·유출 범위는 미확정이다. 회사가 백업 아카이브 접근 증거를 찾지 못했다는 설명은 운영 중인 Microsoft 365 환경의 안전을 보장하지 않는다. [공식 확인 범위](https://www.connectwise.com/company/trust/advisories).

### 2. OpenCode Console 침해 발표…연결한 외부 AI API 키 점검 필요

- 공개: 2026-10-18 02:56 KST 최초 발표, 03:08 KST 수정본 기준이다. [최초 게시물](https://x.com/opencode/status/2111516673953935833), [수정본](https://x.com/opencode/status/2111519637049319818), [발표 버전·시각 대조](https://cellcog.ai/blog/opencode-breach-api-keys/).
- 핵심 요약: OpenCode는 Console 사용자의 1.4%가 영향을 받았으며, 외부 AI 제공자를 연결한 사용자 일부라고 밝혔다. 워크스페이스에 저장된 외부 제공자 API 키의 노출 가능성이 보도됐고, 회사는 피해자에게 이메일을 보냈다고 설명했다. 1.4%는 전체 OpenCode 이용자가 아닌 Console 사용자 기준이다. [회사 발표 수정본](https://x.com/opencode/status/2111519637049319818), [교차 보도](https://www.notebookcheck.net/OpenCode-hacked-users-urged-to-revoke-their-API-keys.1426957.0.html).
- 대응: 통지받은 사용자는 해당 제공자 대시보드에서 키를 폐기·재발급하고 연결 앱을 갱신한다. 사용량·청구 내역도 확인한다. [피해 통지·대응 보도](https://www.notebookcheck.net/OpenCode-hacked-users-urged-to-revoke-their-API-keys.1426957.0.html).
- 왜 중요한가 — 편집부 해석: 연결형 개발 도구에 저장한 키가 다른 서비스 계정의 무단 사용과 비용 위험으로 이어질 수 있다. 제공자별 키와 권한을 분리하는 것이 유리하다.
- 확인 수준: 공식 X 직접 열람이 제한돼 재현된 발표와 보도를 교차확인했다. 무단 과금은 사용자 신고이며, 전체 악용 규모·침입 경로·실제 모델 증류 수행은 확인되지 않았다. [보도](https://www.notebookcheck.net/OpenCode-hacked-users-urged-to-revoke-their-API-keys.1426957.0.html), [회사 주장과 확인 한계](https://exame.com/inteligencia-artificial/opencode-relata-ataque-de-destilacao-em-massa-e-alerta-usuarios-afetados/).
