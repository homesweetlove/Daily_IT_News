## IT 이슈

### 1. Anthropic, Claude Haiku 5.5 출시…요청 길이에 따라 API 단가 차등 적용

- **핵심 요약:** Anthropic은 10월 7일 `Claude Haiku 5.5`를 출시했다. 공식 발표의 표준 API 가격은 프롬프트 10만 토큰 이하에서 입력 100만 토큰당 **0.10달러**, 출력 **0.50달러**다. 10만 토큰을 넘으면 각각 **0.50달러·2.50달러**다. 같은 발표에서 Sonnet 5.5 캐시 읽기 단가도 100만 토큰당 0.20달러에서 **0.10달러**로 낮췄다. [Anthropic 공식 발표·가격표](https://www.anthropic.com/claude-haiku-5-5)
- **왜 중요한가 — 편집부 분석:** 대량 분류·요약처럼 범위가 제한된 작업에서 모델 선택과 요청 길이가 운영비를 좌우할 수 있다. 캐시 읽기 가격 인하를 전체 API 요금의 일괄 인하로 해석해서는 안 된다.
- **관찰 포인트:** 모델 ID는 `claude-haiku-5-5`이며, 회사는 AWS·Google Cloud·Azure에서도 이용 가능하다고 밝혔다. 실제 작업의 토큰 사용량과 성공률로 비용을 평가해야 하며, 이번 리포트는 회사의 성능 우위·평균 비용 절감 홍보 수치를 독립 검증 결과로 인용하지 않았다. [제공 현황·가격 조건](https://www.anthropic.com/claude-haiku-5-5)

### 2. Microsoft, 로컬·클라우드 AI 결합 전략과 RTX Spark PC 예약판매 발표

- **핵심 요약:** Microsoft는 10월 7일 Windows의 ‘하이브리드 인텔리전스’ 전략을 발표하며, RTX Spark 기반 Surface Laptop Ultra와 Surface RTX Spark Dev Box의 예약판매를 시작한다고 밝혔다. 발표 기준 Laptop Ultra의 판매 시작은 **10월 16일**, Dev Box의 미국 출하는 **11월** 예정이다. Windows용 Microsoft Execution Containers(MXC)의 정식 제공도 발표했다. [Windows 공식 발표](https://blogs.windows.com/windowsexperience/2026/10/07/building-windows-for-hybrid-intelligence/)
- **왜 중요한가 — 편집부 분석:** 로컬 실행과 클라우드 이용을 조합하는 PC 전략에서 연산 자원뿐 아니라 에이전트의 접근 범위·신원·관리 정책이 함께 다뤄지고 있다. 로컬 처리만으로 모든 정보 접근·보안 문제가 해결되는 것은 아니다.
- **관찰 포인트:** Copilot의 하이브리드 기능은 향후 수개월에 걸쳐 제공될 예정이며, 기기·시장·반도체 플랫폼에 따라 시점이 달라질 수 있다. 예약판매, 실제 출하, 소프트웨어 기능 제공을 구분하고 국내 판매 일정으로 확대 해석하지 않는다. 공급사 비교 성능·‘가장 안전’ 등의 홍보 문구는 제외했다. [제공 일정·제약](https://blogs.windows.com/windowsexperience/2026/10/07/building-windows-for-hybrid-intelligence/)

## 보안 이슈

### 1. Cisco, NX-OS 보안 강화 릴리스 공개…최대 CVSS 9.8

- **핵심 요약:** Cisco는 10월 7일 16:00 UTC(10월 8일 01:00 KST)에 NX-OS 보안 강화 공지를 처음 공개했다. 내부 검사에서 발견한 여러 취약점을 유형별로 묶어 CVE 6개를 부여했으며, 단순히 ‘버그 6개’라는 뜻은 아니다. `CVE-2026-76455`와 `CVE-2026-76459` 유형의 최고 CVSS 3.1 점수는 **9.8**이다. 취약 릴리스를 사용하는 해당 제품은 설정과 무관하게 영향을 받는다. [Cisco 공식 공지](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-hardening-nxosw1-cWzSbtR)
- **왜 중요한가 — 편집부 분석:** 스위치·패브릭 장비의 접근 통제와 메모리 처리 등 여러 보안 경계를 보강하는 업데이트다. 특정 기능을 껐다는 이유만으로 적용 대상에서 제외해서는 안 된다.

주요 제품의 최초 수정 릴리스는 다음과 같다. [공식 수정표](https://team-development.cisco.com/c/en/us/support/docs/csa/cisco-sa-hardening-nxosw1-cWzSbtR.html)

| 제품·현재 계열 | 최초 수정 릴리스 |
| --- | --- |
| Nexus 3000 / 9000 독립 NX-OS: 10.3 이하 / 10.4 / 10.5 / 10.6 | 각각 10.3(10) / 10.4(8) / 10.5(6) / 10.6(4) |
| MDS 9000: 9.4 | 9.4(5a); 9.3 이하는 수정 계열로 전환 |
| Nexus 7000: 8.4 | 8.4(14); 8.3 이하는 수정 계열로 전환 |
| Nexus 9000 ACI: 16.0 이하 / 16.1 / 16.2 | 각각 16.0(9h) / 16.1(6g) / 16.2(3g) |

- **대응·확인 수준:** UCS Fabric Interconnect도 대상이며 관리 모드별 수정 버전이 다르므로 원문의 전체 표와 대조해 업그레이드한다. 공식 우회책은 없다. 공급사 공지·수정표의 확인 수준은 높으며, Cisco는 알려진 악성 사용이 없다고 밝혔다. 이는 악용 불가능하다는 보장이 아니다. [대상·대응·악용 상태](https://team-development.cisco.com/c/en/us/support/docs/csa/cisco-sa-hardening-nxosw1-cWzSbtR.html)

### 2. Atlassian 파일 접근 취약점, 허니팟에서 공격 시도 관측

- **핵심 요약:** SANS ISC는 10월 7일 `CVE-2026-21589` 악용 시도가 허니팟에 도달했다고 보고했다. 원문은 전날부터 관측했다고 설명하며 최종 갱신 시각은 14:59:33 UTC(23:59:33 KST)다. 이는 **새 공격 시도 보고**로, 10월 5일 발표된 패치와 구분한다. 공격 요청 관측을 실제 서비스의 침해·정보 유출 성공으로 해석하지 않는다. [SANS ISC 관측](https://dshield.org/diary/Scans%2Bfor%2BAtlassian%2Bvulnerablity%2BCVE202621589/33406)
- **영향:** 공급사 평가는 **Critical·CVSS 4.0 9.3**이다. 인증 없이 웹 애플리케이션 루트 내부의 특정 파일에 접근할 수 있으나 정확한 파일명·경로를 알아야 하며, 디렉터리 목록 조회 기능은 아니다. 아래는 주요 제품의 수정 버전이다. [Atlassian 공식 권고](https://confluence.atlassian.com/security/cve-2026-21589-arbitrary-file-access-vulnerability-impacts-multiple-products-1870495748.html)

| 제품 | 지원 계열별 수정 버전 |
| --- | --- |
| Bitbucket Data Center | 9.4.26 / 10.2.8 / 10.5.1 |
| Confluence Data Center | 9.2.26 / 10.2.19 |
| Jira Software Data Center | 9.12.40 / 10.3.26 / 11.3.12 |
| Jira Service Management Data Center | 5.12.40 / 10.3.26 / 11.3.12 |

- **왜 중요한가 — 편집부 분석:** 공개 서비스에 대한 공격 요청이 보고된 만큼, 패치 여부와 외부 노출 상태를 함께 점검해야 한다.
- **대응·확인 수준:** Bamboo·Crowd·Crucible·Fisheye도 포함된다. 제품·계열에 맞게 패치하고, 지연 시 외부 접근 제한과 공급사 WAF·프록시 완화 지침을 적용한다. 로그의 경로 우회 흔적도 조사한다. Cloud는 패치 완료됐으며 고객 조치가 필요 없다는 안내다. 수정 정보는 공식 권고로 확인했지만 공격 활동은 SANS의 관측 범위에 한정하며, 공격자 귀속·침해 성공은 미확인이다. [전체 수정표·완화·탐지 지침](https://confluence.atlassian.com/security/cve-2026-21589-arbitrary-file-access-vulnerability-impacts-multiple-products-1870495748.html)
