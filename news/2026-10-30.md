## IT 이슈

### 1. Mistral Large 4 가중치 공개…호스팅 API 제공과 다운로드 공개는 구분

**핵심 요약:** 10월 29일 공개 자료에서 Mistral Large 4, 일명 Le Chonk의 다운로드 가능한 가중치를 확인했습니다. 공식 모델 카드는 약 1조 매개변수의 MoE 구조, 100만 토큰 문맥, 텍스트·이미지 입력과 텍스트 출력을 명시합니다. 이번 소식의 핵심은 자체 인프라에서 사용할 가중치 공개이며, 기존 API 접근과 구분됩니다. [공식 발표](https://mistral.ai/news/mistral-large-4-oss/) · [모델 카드](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B) · [29일 공개 안내](https://huggingface.co/blog/mistral-large4)

**왜 중요한가 — 편집부 분석:** 대형 멀티모달 모델을 자체 환경에서 평가·운영할 선택지가 추가됐습니다. 다만 공개 가중치라는 이유만으로 일반 PC에서 쉽게 실행되거나 모든 작업에서 성능 우위가 보장되지는 않습니다.

**도입 시 확인할 점:** Mistral Ecosystem Open-Weight License는 수정된 MIT 계열 라이선스이며, 개발사는 Model-as-a-Service 사업의 상업적 사용에 별도 라이선스를 요구한다고 설명합니다. 일반 MIT 라이선스와 동일하다고 표기하지 않았습니다. 실제 배포 전 라이선스 원문과 인프라 요구 사항을 확인해야 합니다. [개발사 설명](https://mistral.ai/news/mistral-large-4-oss/) · [라이선스 원문](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B/blob/main/LICENSE)

### 2. AWS 매출 39.3% 증가…성장 지표와 투자 부담을 함께 확인

**핵심 요약:** Amazon은 10월 29일 2026년 3분기 실적을 발표했습니다. AWS 매출은 약 **460억 달러**, 전년 동기 대비 **39.3% 증가**했고, AWS 영업이익은 약 **178억 달러**였습니다. Amazon 전체 매출은 약 **2,019억 달러**로 12% 늘었습니다. [공식 실적](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Third-Quarter-Results/default.aspx)

**왜 중요한가 — 편집부 분석:** 클라우드 수요 확대와 이를 뒷받침하는 인프라 투자 부담을 함께 보여줍니다. AWS 전체 성장률을 AI 서비스만의 성장률로 해석해서는 안 됩니다.

**관찰 포인트:** Amazon 전체의 최근 12개월 잉여현금흐름은 **424억 달러 순유출**이었습니다. 회사는 주로 AI 관련 설비 투자 증가를 배경으로 설명했습니다. 이는 ‘이번 분기만의 현금 유출’이나 ‘AWS 부문 손실’이라는 뜻이 아닙니다. 실적·전망·주가 반응을 섞지 않고 비교할 필요가 있습니다. [현금흐름 기간·정의](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Third-Quarter-Results/default.aspx)

## 보안 이슈

### 1. PHP2Shell, PAN-OS 관리 인터페이스 공격 악용 후속 확인

**새로 확인된 내용:** Unit 42는 10월 29일 11:00 PT(18:00 UTC, 한국 시간 30일 03:00) 갱신에서 인터넷에 노출된 PAN-OS 관리 인터페이스에 대한 실제 악용을 설명했습니다. Dream Research가 보고한 PHP2Shell과 Linux 커널 권한 상승 취약점의 연계 공격에 대해, 같은 공격 도구와 결과를 독립 확인했다고 밝혔습니다. [Unit 42 갱신](https://unit42.paloaltonetworks.com/cve-2026-109618-cve-2026-109619/) · [연구진 보고](https://dreamgroup.com/blog/chained-php2shell-exploit-roots-25-servers)

**왜 중요한가 — 편집부 분석:** 기존 PHP 취약점 공개의 반복이 아니라 특정 보안 장비에서의 악용 확인입니다. 경계 장비의 관리면 노출은 조직 내부 접근 위험으로 이어질 수 있어 우선 점검 대상입니다.

**대응·영향 범위:** 공급사는 영향 범위를 관리 웹 UI와 XML API로 설명하며, GlobalProtect 포털·게이트웨이는 대상이 아니라고 명시합니다. 관리 접근을 신뢰된 내부 주소·점프 호스트로 제한하고, 현재 PAN-OS 분기에 맞는 수정 빌드를 공식 표와 대조해 적용하세요. 다른 분기의 수정 버전을 그대로 비교해서는 안 됩니다. [영향 범위·수정표·완화책](https://security.paloaltonetworks.com/CVE-2026-109618)

**확인 수준:** 이번 항목은 공급사와 연구진의 기술적 확인을 근거로 합니다. 공격자 국적·AI 사용 여부나 모든 노출 장비의 침해를 단정하지 않습니다. Unit 42의 과거 23일 분석은 25일 철회된 기록이 있어, 이번 **29일 새 확인**과 구분했습니다. [갱신·철회 이력](https://unit42.paloaltonetworks.com/cve-2026-109618-cve-2026-109619/)

### 2. Arista, eMudhra 인증서 대응 권고 갱신…에이전트 수정 범위 주의

**핵심 요약:** Arista는 Security Advisory 0201을 10월 29일 **1.2판**으로 갱신하며 설명과 추가 릴리스 정보를 보완했습니다. eMudhra 중간 인증기관 키 유출과 관련해 손상된 인증서 체인을 신뢰하는 소프트웨어의 중간자 공격 위험을 다룹니다. 신규 키 유출 사건이 아니라 제품별 대응의 후속 변경입니다. [공식 권고·변경 이력](https://www.arista.com/en/support/advisories-notices/security-advisory/24847-security-advisory-0201)

**왜 중요한가 — 편집부 분석:** 인증서 신뢰 문제가 개별 브라우저에만 국한되지 않으며, 네트워크 장비의 외부 TLS 연결과 관리 연동도 확인해야 함을 보여줍니다.

**대응·관찰 포인트:** 제품·EOS 버전에 맞는 수정 릴리스와 완화 절차를 적용하세요. 권고는 TerminAttr 업그레이드의 EOS–CloudVision 연결 수정과 커스텀 스크립트 등의 외부 TLS 경로를 구분합니다. 외부 연결 스크립트·에이전트가 있으면 TerminAttr만 올렸다고 전체 대응이 끝났다고 볼 수 없습니다. 일부 제품은 수정판 안내가 아직 진행 중이므로 모든 제품에 패치가 준비됐다고 단정하지 않았습니다. [제품별 수정·완화 범위](https://www.arista.com/en/support/advisories-notices/security-advisory/24847-security-advisory-0201)
