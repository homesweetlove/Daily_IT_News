## IT 이슈

### 1. SpaceX, 미국 800MHz 주파수 인수 계약…Starlink Mobile 확장 추진

- **핵심 요약:** 10월 9일 Reuters 보도에 따르면 SpaceX는 Grain Management의 미국 전국 800MHz 주파수 포트폴리오 전량을 인수하기로 합의했다. 계약 자체는 미국 현지 10월 8일 발표됐으며, **FCC 승인과 거래 종결 조건이 남아 있다**. [Reuters 보도](https://www.business-standard.com/world-news/spacex-takes-aim-at-us-wireless-carriers-with-spectrum-acquisition-126100900123_1.html), [Grain 공식 발표](https://www.prnewswire.com/news-releases/grain-management-announces-definitive-agreement-to-sell-nationwide-800-mhz-spectrum-portfolio-to-spacex-302902974.html)
- **왜 중요한가 / 영향:** Grain은 이 주파수를 지상·위성 직접 연결 서비스를 지원하는 자원으로 설명했다. **편집부 해석:** 위성 통신과 지상 이동통신을 결합하려는 전략의 진전이지만, 계약 체결만으로 전국 상용망이 완성되는 것은 아니다.
- **관찰 포인트:** 규제 승인, 실제 망 구축과 서비스 제공 조건을 확인해야 한다. 공식 발표에서 확인되지 않은 거래 금액이나 즉각적인 서비스 개시를 단정하지 않는다.

### 2. Indosat·F5, 여러 AI 모델의 이용·과금을 통합하는 기업용 플랫폼 출시

- **핵심 요약:** Indosat와 F5는 10월 9일 ‘Indosat Intelligence Suite’를 발표했다. 회사 설명에 따르면 여러 AI 모델을 하나의 인터페이스로 제공하고, 비용·품질·지연시간에 따른 요청 라우팅과 팀별 크레딧 배분, 이용량 측정·기록 기능을 포함한다. 기업은 이날부터 모델 목록·가격·문서를 확인하고 접근을 신청할 수 있다. [공식 발표](https://www.f5.com/company/news/press-releases/indosat-and-f5-launch-intelligence-suite-a-token-factory-to-unlock-ai-across-asia)
- **왜 중요한가 / 영향:** **편집부 해석:** 모델을 각각 연결하는 것뿐 아니라 사용량·권한·비용을 통합 관리하는 계층이 기업용 AI 도입의 중요한 구성요소가 되고 있음을 보여준다.
- **관찰 포인트:** 데이터 처리 위치, 제공 모델과 접근 조건, 과금 단위를 계약·문서에서 확인할 필요가 있다. 발표에 포함된 보안·성능 향상 설명을 독립 검증된 효과로 간주하지 않는다.

### 3. Safari Technology Preview 254 공개…CSS 기능·웹 호환성 시험 범위 확대

- **핵심 요약:** Apple의 WebKit 프로젝트는 Safari Technology Preview 254를 공개했다. 공식 릴리스 노트에는 CSS `interpolate-size`·`calc-size()` 지원과 JavaScript·접근성·WebGPU 등의 수정 사항이 포함됐다. 원문 날짜는 10월 8일이며, MacRumors의 보도 시각은 **10월 8일 20:11 PDT, 한국시간 10월 9일 12:11**로 조사 구간 안이다. [공식 릴리스 노트](https://webkit.org/blog/18420/release-notes-for-safari-technology-preview-254/), [보도 시점](https://www.macrumors.com/2026/10/08/apple-releases-safari-technology-preview-254/)
- **왜 중요한가 / 영향:** **편집부 해석:** 웹 개발팀이 새 CSS 동작과 기존 페이지의 회귀 문제를 정식 브라우저 반영 전에 시험할 기회다.
- **관찰 포인트:** 이번 배포는 시험판이다. 시험판의 지원 기능을 모든 정식 Safari 사용자에게 이미 제공되는 기능으로 혼동하지 말고, 실제 사용 환경의 호환성을 따로 점검한다.

## 보안 이슈

### 1. Canonical·Ubuntu DDoS 대응…대부분 서비스 복구했지만 복구 작업은 계속

- **핵심 요약:** Canonical은 지속적인 분산 서비스 거부(DDoS) 공격으로 일부 서비스가 간헐적으로 이용 불가능할 수 있다고 공지했다. **10월 9일 11:40 UTC(한국시간 20:40)의 후속 안내**에서는 대부분의 영향받은 서비스가 이용 가능해졌지만 복구 작업은 계속되고 있다고 밝혔다. 최초 공지는 10월 8일이며, 이번 항목의 새 소식은 9일 복구 업데이트다. [공식 공지·후속 답글](https://discourse.ubuntu.com/t/ddos-on-canonical-and-ubuntu-websites/89064)
- **왜 중요한가 / 영향:** 서비스 가용성에 실제 영향을 준 공격이다. **편집부 해석:** 관련 온라인 서비스에 의존하는 배포·운영 작업에서는 장애와 로컬 설정 문제를 구분할 필요가 있다. 이 공지만으로 데이터 유출이나 배포 패키지 변조, Ubuntu 제품 취약점 악용이 확인됐다고 볼 수는 없다.
- **대응:** 작업 전 [Canonical 서비스 상태](https://status.canonical.com/)를 확인하고 실패한 다운로드·갱신 작업은 복구 상태를 확인한 뒤 재시도한다. 오류를 우회하려고 패키지 서명 검증을 끄지 않는다.
- **확인 수준:** 운영사가 공격과 복구 진행을 직접 확인했다. 공개 자료만으로 공격자, 전체 피해 서비스 범위, 완전 복구 시각은 확정하지 않는다.

### 2. Hermes Agent 로그인 세션 탈취 결함 상세 공개…0.21.6 이상으로 갱신 권고

- **핵심 요약:** Tenable은 10월 9일 15:15:46 UTC(한국시간 10월 10일 00:15:46)에 `TRA-2026-65` 권고문을 공개했다. Hermes Agent의 네이티브 로그인 흐름에서 서버와 브라우저가 리디렉션 URL을 다르게 해석해, 피해자가 로그인한 뒤 인증 코드가 공격자가 통제하는 주소로 전달되고 세션이 탈취될 수 있다는 내용이다. Tenable은 위험도를 **High**, 영향 범위를 **0.21.6 미만**, 수정 버전을 **0.21.6 이상**으로 명시했다. [연구 권고문](https://www.tenable.com/security/research/tra-2026-65)
- **왜 중요한가 / 영향:** **편집부 해석:** PKCE를 사용하는 로그인이라도 리디렉션 검증에 사용하는 URL 해석이 브라우저 동작과 어긋나면 계정 보호가 깨질 수 있다. 연구에 설명된 공격에는 피해자의 로그인 과정이 필요하며, 무조건적인 무인 계정 탈취로 표현하지 않는다.
- **대응:** 0.21.6 이상으로 갱신하고 [수정 릴리스](https://github.com/NousResearch/hermes-agent/releases/tag/v0.21.6)를 확인한다. 침해가 의심되면 로그인·토큰 이용 이력을 조사하고 해당 세션을 폐기한다. 이는 운영자를 위한 추가 점검 권고다.
- **확인 수준·시점:** 기술 문제와 수정 안내는 연구기관 권고문 및 [유지관리자 수정 PR](https://github.com/NousResearch/hermes-agent/pull/130685)로 확인된다. 실제 공격에 악용됐다는 근거는 확인하지 못했다. 수정 PR은 10월 1일, 릴리스는 10월 8일 공개됐으며 **이번 신규 뉴스는 10월 9일의 상세 권고문 발표**다. 해당 권고문에는 CVE 번호가 기재돼 있지 않다.
